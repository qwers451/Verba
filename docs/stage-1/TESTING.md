# Программа испытаний этапа 1

## Автоматические проверки

```bash
cd frontend && npm run lint && npx tsc --noEmit && npm run build
docker-compose up -d --build
docker-compose exec -T backend pytest -q
curl -f http://localhost:8000/api/v1/
curl -f http://localhost:3000
```

## Ручной чек-лист

1. Зарегистрировать нового пользователя и войти.
2. Загрузить корректный PDF; убедиться, что в списке показаны страницы и фрагменты.
3. Попытаться загрузить файл не в PDF и получить понятное сообщение.
4. Запустить тренировку, ответить на вопросы, открыть историю и отчёт.
5. В «Настройках» перейти на тестовую страницу ЮKassa, подтвердить тестовый платёж Pro, вернуться в приложение и проверить изменение лимита и появление операции.
6. Убедиться, что в разделах тренера, истории и настроек указан mock/demo-статус там, где интеллектуальная логика ещё не реализована.
7. На отдельной учётной записи проверить, что чужой материал и сессия недоступны по прямому API-адресу.

## Результат, который фиксируется в отчёте

Сохранить вывод автоматических проверок и четыре скриншота из `README.md`. Скриншоты должны быть сделаны на запущенной версии, а не на статическом макете.
