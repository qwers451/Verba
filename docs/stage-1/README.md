# Этап 1. Архитектура и пользовательский MVP

Этот каталог содержит материалы для отчёта по первому этапу проекта Verba AI.

## Результат этапа

Подготовлен работающий веб-MVP: пользователь создаёт учётную запись, загружает PDF, запускает тренировочную сессию, видит историю и управляет тарифом через тестовый checkout ЮKassa. Система развёртывается одной Docker Compose-конфигурацией.

Полный интеллектуальный контур не включён в результат этапа: генерация вопросов, оценка ответов и рекомендации используют маркированный `mock`-провайдер. Это не выдаётся за работу LLM и будет заменено в этапах 2–3.

## Демонстрация

Локальные адреса после `docker-compose up -d --build`:

- интерфейс: `http://localhost:3000`;
- API: `http://localhost:8000/api/v1`;
- OpenAPI: `http://localhost:8000/docs`.

Публичный адрес тестового сервера будет добавлен после выполнения этапа 4.
