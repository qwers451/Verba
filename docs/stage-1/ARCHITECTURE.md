# Архитектура и фрагменты кода для отчёта

## Схема взаимодействия

```text
Browser (Next.js) → FastAPI /api/v1 → PostgreSQL + pgvector
                         ├────────→ файловое хранилище PDF
                         └────────→ Chroma (локальный индекс)
```

## Что приложить как подтверждение разработки

| Компонент | Файл | Что показывает |
| --- | --- | --- |
| Авторизация и профиль | `backend/app/api/auth.py`, `backend/app/api/router.py` | JWT-сессия, регистрация, учёт квоты |
| Защита данных | `backend/app/api/router.py` | Проверка владельца PDF и сессии перед выдачей/изменением |
| Модель данных | `backend/app/models/models.py` | Пользователь, материал, сессия, диалог и тестовая операция |
| Frontend-кабинет | `frontend/src/app/(dashboard)/dashboard/page.tsx` | Отображение реальных данных API |
| Тарифы | `frontend/src/app/(dashboard)/settings/page.tsx`, `backend/app/services/yookassa_service.py` | Тестовый checkout ЮKassa и правила тарифов |
| Инфраструктура | `docker-compose.yml`, `frontend/Dockerfile`, `backend/Dockerfile` | Воспроизводимый локальный стенд |

Не включайте в публичный отчёт `.env`, токены, пароли, секреты и будущие промпты/параметры интеллектуального модуля.

## Данные и ответственность

- Next.js отвечает за интерфейс и вызовы API.
- FastAPI проверяет JWT, права владельца, квоты и выполняет бизнес-операции.
- PostgreSQL хранит учётные записи, метаданные материалов, сессии и тестовые операции.
- PDF и локальный индекс вынесены в Docker volumes и не попадают в репозиторий.
- Секретный ключ ЮKassa хранится только в локальном `.env`; сервер сверяет итоговый статус платежа с API ЮKassa до активации тарифа.
