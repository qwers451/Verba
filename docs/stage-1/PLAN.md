# План и критерии готовности этапа 1

| Направление | Результат | Критерий приёмки |
| --- | --- | --- |
| Frontend | Адаптивные страницы лендинга, кабинета, материалов, тренировок, истории, помощи и настроек | Пользователь проходит основной сценарий в браузере, в том числе на мобильной ширине |
| Backend | REST API, авторизация JWT, пользовательские данные и изоляция ресурсов | Пользователь получает только свои материалы, сессии и операции |
| Материалы | Приём PDF, сохранение, извлечение текста и фрагментация | PDF виден в списке; число страниц и фрагментов сохранено |
| Тарифы | Базовый и Pro-тариф, учёт месячной квоты | Лимит сессий проверяется сервером |
| Тестовая оплата | Checkout ЮKassa в тестовом магазине | Операция отражается в истории и меняет тариф только после подтверждённого статуса; деньги не списываются |
| Инфраструктура | Docker Compose: frontend, backend, PostgreSQL/pgvector | Контейнеры собираются и сервисы отвечают по локальным адресам |
| Границы этапа | Mock-вопросы, mock-оценка и mock-рекомендации | В UI и документации указан demo/mock-статус; LLM, рекомендации и голосовые интервью не заявлены как готовые |

## Основной пользовательский сценарий

1. Регистрация и вход.
2. Загрузка PDF в «Мои материалы».
3. Запуск тренировочной сессии по выбранному материалу.
4. Ответы на вопросы и просмотр результата.
5. Просмотр истории в «Мои экзамены».
6. Активация Pro через тестовый интерфейс в настройках.
