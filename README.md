# Verba AI - SaaS-платформа для устных аттестаций

Техническое решение проекта основано на архитектуре Retrieval-Augmented Generation (RAG) и представляет собой веб-платформу, обеспечивающую интеллектуальную подготовку студентов к устным аттестациям на основе их собственных учебных материалов.

## 🧠 Принцип работы (Архитектура RAG)

После загрузки документов система выполняет извлечение текста, его семантическое разбиение и индексирование в векторной базе данных (PostgreSQL + pgvector). 
При проведении тренировочного собеседования по каждому вопросу автоматически извлекаются наиболее релевантные фрагменты учебных материалов, которые используются большой языковой моделью (LLM) для генерации вопросов, проверки ответов и формирования рекомендаций.

## ⚡ Основной функционал

Платформа поддерживает:
- 🎙️ **Голосовое и текстовое взаимодействие**: Пользователи могут вводить ответы как текстом, так и голосом (с использованием Web Speech API).
- 📈 **История и аналитика**: Система ведет историю обучения пользователя и формирует детальную аналитику по уровню освоения отдельных тем, указывая сильные и слабые стороны.
- 🧩 **Модульность**: Архитектура решения является модульной (Next.js на фронтенде, FastAPI на бэкенде) и предусматривает возможность интеграции с образовательными платформами и корпоративными системами обучения.

## 🛠️ Стек технологий

- **Frontend**: Next.js 14, Zustand, TailwindCSS
- **Backend**: Python 3.12, FastAPI, SQLAlchemy (Async)
- **База данных**: PostgreSQL с расширением `pgvector`
- **Инфраструктура**: Docker & Docker Compose
- **Тестирование**: Pytest

## 🚀 Как запустить проект

Убедитесь, что у вас установлен Docker и Docker Compose.

```bash
docker-compose up -d --build
```

Платформа будет доступна по адресам:
- **UI Приложение (Next.js)**: http://localhost:3000
- **API (FastAPI)**: http://localhost:8000/api/v1
- **Документация API**: http://localhost:8000/docs
