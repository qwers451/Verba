# Verba AI - SaaS-платформа для устных аттестаций

Verba AI — веб-платформа для подготовки студентов к устным аттестациям по собственным учебным материалам.

Текущая версия реализует **этап 1**: клиентскую и серверную архитектуру, авторизацию, личный кабинет, загрузку и обработку PDF, историю тренировок, тарифы и тестовую оплату. Интеллектуальные сценарии вопросов, оценки и рекомендаций пока намеренно работают в прозрачном `mock`-режиме; их развитие относится к этапам 2–3.

## 🧠 Принцип работы (Архитектура RAG)

После загрузки PDF система извлекает текст, разбивает его на фрагменты и сохраняет метаданные для последующего поиска. Архитектура подготовлена к подключению RAG и LLM, но по умолчанию использует `DEFAULT_LLM_PROVIDER=mock` и не заявляет имитацию как результат работы нейросети.

## ⚡ Основной функционал

Платформа поддерживает:
- 🔐 **Личный кабинет**: регистрация, авторизация, индивидуальная квота и разграничение доступа к материалам и сессиям.
- 📄 **Материалы**: загрузка PDF, извлечение текста, фрагментация, просмотр и удаление материалов.
- 📈 **Тренировки**: запуск сценария, ответы, история и экран результата. На этапе 1 вопросы и оценка — mock.
- 💳 **Тарифы**: базовый и Pro, включая тестовый checkout ЮKassa без списания средств.
- 🧩 **Модульность**: Next.js + FastAPI + PostgreSQL/pgvector, готовые границы для дальнейшей интеграции LLM.

## 🛠️ Стек технологий

- **Frontend**: Next.js 15, Zustand, TailwindCSS
- **Backend**: Python 3.12, FastAPI, SQLAlchemy (Async)
- **База данных**: PostgreSQL с расширением `pgvector`
- **Инфраструктура**: Docker & Docker Compose
- **Тестирование**: Pytest

## 🚀 Как запустить проект

Убедитесь, что у вас установлен Docker с Docker Compose. Для развёртывания вне локальной машины сначала подготовьте переменные окружения:

```bash
cp .env.example .env
```

Замените в `.env` значения `POSTGRES_PASSWORD` и `JWT_SECRET_KEY` на надёжные секреты. Для локального запуска этот шаг необязателен: Compose использует безопасные для разработки значения по умолчанию.

```bash
docker-compose up -d --build
```

Платформа будет доступна по адресам:
- **UI Приложение (Next.js)**: http://localhost:3000
- **API (FastAPI)**: http://localhost:8000/api/v1
- **Документация API**: http://localhost:8000/docs

Данные PostgreSQL, загруженные материалы и векторный индекс хранятся в именованных Docker volumes. Они не попадают в Git и сохраняются при обычном `docker-compose down`.

Для полного удаления локальных данных проекта используйте:

```bash
docker-compose down -v
```
