ОПИСАНИЕ ПРОЕКТА
Вы помогаете разрабатывать SaaS платформу для подготовки к экзаменам.
Проект анализирует PDF файлы и проводит собеседования.
Система задает вопросы и оценивает ответы.

ТЕХНОЛОГИЧЕСКИЙ СТЕК
Бэкенд работает на Python и FastAPI.
Фронтенд работает на NextJS.
Клиентское состояние управляется через Zustand.
Данные хранятся в PostgreSQL.

ОСНОВНЫЕ ЗАДАЧИ ИИ
Пишите функциональный код.
Используйте строгую типизацию для всех переменных и функций.

Разделяйте обработчики запросов и логику приложения в FastAPI.
Пишите безопасные запросы к базе данных.
